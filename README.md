# 🖥️ Computer Parts Adventure — Kids Learning Website

A fun, interactive website for kids to learn about computer parts!
Complete with colorful animations, sound effects, and illustrated SVG images.

## 🚀 How to Open

1. Unzip the folder
2. Open `index.html` in any web browser (Chrome, Firefox, Edge, Safari)
3. No internet required for the sounds and images — they work offline!
   (Internet needed only to load the Google Fonts for extra-pretty text)

## 🎮 How to Play

- **Click any card** to learn about that computer part
- Each part plays its own **unique sound effect**
- A **green checkmark** appears when you've learned a part
- Learn **all 12 parts** to trigger the celebration! 🎉
- **Score tracker** in the top right shows your progress

## 🎵 About the Sounds

All sounds are **generated in real-time** by the Web Audio API built into your browser.
No sound files needed — the code creates beeps, whooshes, and chimes on the fly!
Each computer part has its own themed sound (fans whir, keyboards click, etc.)
